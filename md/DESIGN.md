# ParkSmart Design System (Verified from Stitch)

## Core Identity
- **Vibe**: Modern urban mobility fused with precision fintech mechanics.
- **Rules**: High-contrast readouts, crisp card geometry, no excessive glassmorphism.

- **Secondary**: #006A9A (Standard interactive states, route segments)
- **Tertiary (Available/Success)**: #17A18A

- **Background/Surface**: #F9F9F9
- **Neutral Surface**: #EEEEEE
- **White**: #FFFFFF
- **Text Primary**: #14202B
